# Support

For support, open an issue in the project repository.

Include:

- Chrome version.
- Operating system.
- Whether the PDF is local `file://` or web-hosted.
- Selected JPG quality and resolution scale.
- Whether ZIP mode was enabled.
- The exact popup status or error message.

For local PDFs, first confirm that **Allow access to file URLs** is enabled for the extension in `chrome://extensions`, then reload the PDF tab.
