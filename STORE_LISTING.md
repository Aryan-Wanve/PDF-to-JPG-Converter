# Chrome Web Store Listing

## Name

PDF to JPG Converter

## Short Description

Convert the PDF open in Chrome into JPG page images locally, with quality, scale, and ZIP controls.

## Full Description

PDF to JPG Converter turns the PDF open in your active Chrome tab into high-quality JPG images without uploading the document anywhere.

Choose JPG quality, select a resolution scale, optionally export a ZIP, and click Convert. The extension renders each PDF page locally in your browser and automatically saves the result using a clean folder name based on the PDF filename.

## Feature List

- Converts the active PDF tab to JPG images.
- 100% local browser processing.
- No uploads, no backend, no analytics, no telemetry.
- JPG quality slider from 50 to 100.
- Resolution scale options: 1x, 1.5x, 2x, 3x.
- Optional ZIP export.
- Automatic folder naming from the PDF filename.
- Predictable page filenames such as `page-001.jpg`.
- Progress bar, page counter, ETA, cancellation, and clear result states.
- Dark and light modes.
