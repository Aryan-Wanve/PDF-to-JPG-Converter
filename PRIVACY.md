# Privacy Policy

Effective date: 2026-05-14

PDF to JPG Converter processes PDFs locally inside the user's browser.

## Data Collection

This extension does not collect, sell, share, transmit, or store personal data on external servers.

## PDF Content

PDF files are read only for the purpose of rendering pages into JPG images. Processing happens locally in Chrome using extension-bundled code. PDF contents are not uploaded or sent to any backend.

## Network Activity

The extension does not use analytics, telemetry, advertising, tracking pixels, remote scripts, cloud APIs, or external processing services.

## Permissions

- `activeTab`: detects the PDF open in the current tab after the user invokes the extension.
- `downloads`: saves generated JPG or ZIP files.
- `storage`: remembers export settings.
- `scripting`: reserved for active-tab compatibility workflows.
- `offscreen`: renders PDF pages in an extension-owned offscreen document.
- `<all_urls>` host access: allows Chrome to fetch the active PDF URL for local conversion.

## Contact

For support, use the support contact listed in the Chrome Web Store listing.
