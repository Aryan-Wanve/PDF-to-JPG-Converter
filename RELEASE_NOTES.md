# Release Notes

## v1.0.0 - 2026-05-17

Initial Chrome Web Store launch release.

- Added Manifest V3 Chrome extension scaffold.
- Added local pdf.js rendering pipeline.
- Added JPG quality, resolution scale, and ZIP export settings.
- Added automatic folder and page filename generation.
- Added popup UI with dark/light mode, progress, ETA, cancellation, and result states.
- Added page-level diagnostics and timeout safeguards.
- Added local `file://` PDF access checks and clear local-file guidance.
- Added Chrome downloads integration.
- Added privacy policy, store listing copy, release notes, performance notes, edge-case documentation, and launch asset inventory.
