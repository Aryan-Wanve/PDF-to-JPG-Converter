# Store Assets

Upload these assets in the Chrome Web Store Developer Dashboard.

## Required

- Store icon: `../icons/icon-128.png`
- Small promo tile: `banners/small-promo-440x280.png`
- At least one screenshot: `screenshots/01-popup-ready.png`

## Recommended Upload Set

- `screenshots/01-popup-ready.png`
- `screenshots/02-popup-progress.png`
- `screenshots/03-popup-success.png`
- `screenshots/04-downloads-output.png`
- `banners/small-promo-440x280.png`
- `banners/marquee-1400x560.png`

## Regenerate

```powershell
npm run store-assets
```

All screenshots are 1280x800 PNG files. The small promo tile is 440x280. The marquee promo tile is 1400x560.
